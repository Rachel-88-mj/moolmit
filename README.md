# 물밑 배포 안내

## 모바일 이동 조작

- 입수 후 왼쪽 아래 방향 패드를 누르고 있으면 앞·뒤·좌·우로 헤엄쳐요. 좌우는 고개 회전이 아니라 바라보는 방향 기준 옆걸음 이동이에요.
- 오른쪽 아래 올라가기·내려가기를 누르고 있으면 수심을 조절해요. 왼손으로 패드를 누르며 오른손으로 수심을 조절할 수 있어요.
- 바다 화면을 한 손가락으로 끌면 고개를 돌려 둘러봐요.
- 바다 화면 위에서 두 손가락을 벌리면 앞으로, 오므리면 뒤로 움직여요. 화면 배율을 바꾸는 것이 아니라 실제 위치가 이동해요. 두 손가락을 가만히 두거나 떼면 이동 입력이 끝나요.
- 패드에서 손을 떼면 이동이 멈춰요. 가운데 멈춤 버튼은 이동과 자동 하강을 멈춰요. 호흡에 따른 작은 부유 연출은 계속돼요.
- 화면 전환·앱 전환·터치 취소 시 입력을 해제해요. 초대 공유 창을 열 때도 이동을 멈춰요.
- 이동 패드는 휴대폰·태블릿 터치 환경과 너비 900px 이하 화면에서 표시돼요. 앞뒤 이동은 보는 각도에 따라 위아래로도 움직이며, 네 방향은 고정 나침반 방위가 아니라 카메라 기준이에요.

## 이 장소로 초대하기

- 입수 후 오른쪽 위 **이 장소로 초대하기**를 누르면 현재 장면과 초대 링크를 확인할 수 있어요.
- 공유 이미지에는 수심과 X·Z 좌표, 다이브 타임, 함께한 인원, 초대 주소가 새겨져요.
- 링크에는 수심·X·Z 좌표와 시선 방향·상하 각도가 들어 있어요. 주소는 현재 배포된 사이트 주소를 자동으로 사용해요.
- 받는 사람이 링크를 열고 **초대 장소로 입수하기**를 누르면 해당 위치와 시선에서 시작해요. 움직이는 생물의 위치나 같은 장면까지 복원하지는 않아요.
- **초대 공유하기**는 지원되는 환경에서 기본 공유 창을 열어요. 이미지 파일 공유가 가능하면 이미지도 포함하고, 그렇지 않으면 링크를 공유해요. 대상 앱에 따라 이미지와 글 중 일부만 전송될 수 있으니 전송 내용을 확인해 주세요.
- **링크 복사**와 **이미지 저장**을 각각 사용할 수도 있어요. 사진에 적힌 주소 자체는 클릭할 수 없으니, 이미지와 초대 링크를 함께 보내 주세요.
- 자동 복사가 허용되지 않으면 입력란의 링크가 선택돼요. 직접 복사하면 돼요.
- 로컬 파일로 열면 초대 링크를 만들지 않아요. 배포된 사이트에서 사용해 주세요.

이 폴더를 GitHub에 올리고 Vercel에 연결하면 누구나 접속할 수 있는 사이트가 됩니다. 코딩 없이 웹 화면에서만 진행해요.

## 폴더 구성

- `index.html` : 사이트 본체 (3D 바닷속, 동시접속, 호흡 소리 모두 포함)
- `api/country.js` : 접속자의 국가를 IP로 알려주는 작은 서버 기능 (수트 국기용)
- `og.png` : 스레드, 카카오톡 등에 링크를 올렸을 때 뜨는 미리보기 이미지
- `README.md` : 이 안내서

Supabase 주소와 공개 키는 `index.html` 안에 이미 넣어 두었어요. 공개 키(publishable key)는 원래 웹페이지에 노출되도록 만들어진 키라 그대로 올려도 괜찮아요.

## 1단계. GitHub에 파일 올리기

1. github.com 에 가입하고 로그인해요.
2. 오른쪽 위 `+` 버튼에서 **New repository**를 눌러요.
3. Repository name에 `mulmit`을 입력하고 **Create repository**를 눌러요.
4. 다음 화면에서 **uploading an existing file** 링크를 눌러요.
5. 압축을 푼 폴더 안의 내용물(`index.html`, `og.png`, `README.md`, `api` 폴더)을 전부 선택해서 업로드 칸으로 끌어다 놓아요. 폴더 자체가 아니라 폴더 안의 내용물을 끌어다 놓아야 해요.
6. 아래쪽 **Commit changes**를 눌러요.

업로드 후 저장소 첫 화면에 `api` 폴더와 `index.html`이 바로 보이면 성공이에요.

## 2단계. Vercel로 배포하기

1. vercel.com 에서 **Continue with GitHub**로 가입해요.
2. **Add New → Project**를 누르고, 목록에서 `mulmit` 저장소의 **Import**를 눌러요.
3. Framework Preset은 **Other** 그대로 두고 **Deploy**를 눌러요.
4. 1분 정도 지나면 축하 화면과 함께 사이트 주소가 나와요. 예: `mulmit.vercel.app`

이후 GitHub에서 파일을 고치면 Vercel이 자동으로 다시 배포해요.

## 3단계. 주소 정하고 미리보기 주소 맞추기

1. Vercel 프로젝트에서 **Settings → Domains**로 가요.
2. `○○.vercel.app` 옆 **Edit**를 눌러 원하는 이름으로 바꿔요. 이미 쓰이는 이름이면 `mulmit-dive`처럼 바꿔 보세요.
3. GitHub 저장소에서 `index.html`을 열고 연필 아이콘(Edit)을 눌러요.
4. `https://mulmit.vercel.app` 이 세 군데 들어 있어요. 모두 실제 주소로 바꾼 뒤 **Commit changes**를 눌러요. (Ctrl+F로 `mulmit.vercel.app`을 찾으면 돼요.)

이 주소는 링크 미리보기 이미지가 뜨게 하는 용도라, 바꾸지 않아도 사이트 자체는 정상 작동해요.

## 4단계. 동시접속 확인하기

1. 휴대폰과 컴퓨터에서 각각 사이트에 들어가 둘 다 **입수하기**를 눌러요.
2. 오른쪽 아래가 "지금 2명이 함께 잠겨 있어요"로 바뀌고, 상대 다이버와 국기 태그가 보이면 성공이에요.

계속 "혼자 잠겨 있어요"로 나오면 Supabase 대시보드에서 프로젝트의 **Realtime 설정**을 열고, 공개 채널 접근(Public access)이 허용되어 있는지 확인해 주세요. 비공개 채널만 허용(Private only)으로 되어 있으면 연결되지 않아요.

## 운영할 때 알아둘 점

- **동시접속 한도** : Supabase 무료 플랜은 실시간 동시 연결 200개까지예요. 그래서 이 사이트는 이미 150명이 들어와 있으면 새로 온 사람을 "혼자 잠수" 모드로 들여보내요(화면은 그대로 즐길 수 있어요). 숫자는 `index.html`의 `ROOM_CAP = 150`에서 바꿀 수 있어요. Supabase Pro(월 25달러)로 올리면 500 근처까지 늘려도 돼요.
- **메시지 한도** : 위치 신호는 움직일 때 초당 약 1.5회, 가만히 있을 때 5초에 한 번만 보내도록 줄여 두었어요. 그래도 사람이 많이 몰리면 무료 플랜의 월 메시지 한도에 빨리 닿을 수 있으니, 스레드 홍보 전에는 Pro 전환을 권해요.
- **일시 정지** : Supabase 무료 프로젝트는 오랫동안 사용이 없으면 일시 정지될 수 있어요. 대시보드에서 다시 켤 수 있어요.
- **Vercel 무료 플랜** : 개인적, 비상업적 용도용이에요. 회사 마케팅으로 운영한다면 Pro 플랜이 필요한지 Vercel 요금 페이지에서 확인해 주세요.
- **미리보기 이미지 갱신** : 링크를 한 번 공유한 뒤 이미지를 바꾸면 예전 이미지가 남아 있을 수 있어요. Facebook 공유 디버거(developers.facebook.com/tools/debug)에 주소를 넣고 다시 가져오기를 누르면 스레드와 인스타에도 반영돼요.

## v2에 새로 생긴 것

- **산호초 바닥** : 아무데나 흩어져 있던 돌들이 가지산호·바다부채·뇌산호·관해면·말미잘로 바뀌었어요. 이미지 파일 없이 전부 코드로 그린 절차적 산호라 로딩이 추가되지 않아요. 돌이 모래 위에 붕 떠 보였던 문제도 같이 고쳤어요.
- **입장 화면** : 입수하기 전에 실시간 접속자 수가 보이고, 이전 다이브 기록(횟수·누적 시간·최고 수심·만난 생물)이 이 브라우저에 저장돼요.
- **이 순간 남기기** : 오른쪽 위 버튼으로 지금 화면을 수심·시간·함께한 인원이 적힌 이미지로 저장하거나 공유해요.
- **인사하기** : 오른쪽 아래 버튼 또는 G 키. 주변 다이버가 손을 흔들어 응답해요.
- **만난 생물 도감** : 고래상어·만타가오리·바다거북·정어리 떼·리프상어·큰돌고래·바라쿠다 떼·흰동가리를 가까이서 1.5초 이상 보면 기록돼요.
- **심해 연출** : 수심 22m 아래에서 생체발광 플랑크톤이 반짝이고, 20m보다 깊으면 가끔 고래 노래가 들려요.
- **딥링크** : 주소 뒤에 `?depth=30&x=10&z=-5`처럼 붙여 특정 수심과 장소로 바로 초대할 수 있어요.

## 추가 해양 생물

- **리프상어 2마리** : 기존 고래상어와 별개예요. 약 2.4~2.5m의 유선형 몸, 삼각 등지느러미, 위쪽이 긴 수직 꼬리, 다섯 아가미와 좌우 꼬리 운동을 표현했어요.
- **큰돌고래 2마리** : 약 2.4~2.5m의 몸에 돌출된 주둥이와 이마, 굽은 등지느러미, 수평 꼬리를 만들었어요. 한 쌍이 상하로 꼬리를 저으며 주기적으로 수면 가까이 올라가요.
- **바라쿠다 32마리** : 약 1m의 가늘고 긴 은빛 몸과 뾰족한 턱, 어두운 옆줄 무늬를 가진 무리가 함께 유영해요.
- **흰동가리 24마리** : 약 15~22cm의 주황색 몸에 검은 테두리를 두른 흰 띠 세 개와 둥근 지느러미를 표현했어요. 실제 말미잘 여섯 군데에 네 마리씩 머물며, 지형 높이에 맞춰 배치되어 바닥으로 잠수하면 만날 수 있어요.
- 네 종 모두 외부 이미지 없이 절차적 곡면과 재질로 만든 근사 표현이며, 실사 동물 스캔은 아니에요. 종마다 한 번의 묶음 렌더링을 사용하고, 상어·바라쿠다는 수심만 천천히 맞출 뿐 다이버를 추격하거나 공격하지 않아요.
