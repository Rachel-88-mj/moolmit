# 물밑 배포 안내

## 모바일 이동 조작

- 바다 화면을 한 손가락으로 끌면 고개를 돌려 둘러봐요. 돌아본 방향이 곧 나아갈 방향이에요.
- 두 손가락을 벌리면 앞으로, 오므리면 뒤로 움직여요. 화면 배율을 바꾸는 것이 아니라 실제 위치가 이동해요. 두 손가락을 떼면 이동이 끝나요.
- 오른쪽 아래 올라가기·내려가기를 누르고 있으면 수심을 조절해요. 앞뒤 이동은 보는 각도에 따라 위아래로도 움직여요.
- 화면 전환·앱 전환·터치 취소 시 입력을 해제해요. 초대 공유 창을 열 때도 이동을 멈춰요. 호흡에 따른 작은 부유 연출은 계속돼요.

## 잠깐 나누는 말풍선

- 입수한 뒤 아래 입력란에 `안녕`처럼 적고 **보내기** 또는 Enter를 눌러요. 최대 100 코드포인트이며 빈 메시지는 보내지 않아요. 한글 조합을 확정하는 Enter는 전송하지 않아요. 입력란 밖의 Enter는 채팅에 초점을 옮기고, Escape는 초점을 해제해요.
- 입력 중에는 이동·자동 하강을 멈추며 W·A·S·D·Q·E·G·공백이 이동이나 인사를 실행하지 않아요. 모바일에서는 안전 영역과 화면 키보드 높이에 맞춰 입력란을 올려요.
- 상대의 머리 옆에 최신 한마디만 표시하고, 5초 중 마지막 0.8초 동안 부드럽게 사라져요. 다시 보내면 최신 말로 바꾸고 5초를 갱신해요. 화면 밖·시야 뒤에서는 숨기며 퇴장·연결 해제 때 제거해요. 내 다이버는 1인칭이므로 하단에 **나** 확인 말풍선만 보여요.
- 연결·동기화·입수 등록이 끝나야 전송해요. 서버 방송 확인(`broadcast.ack: true`)의 `ok` 뒤에만 내 말풍선을 표시하며, 3.5초 안에 확인되지 않으면 재전송 안내를 보여요. 서버 확인은 상대가 실제로 읽었다는 뜻이 아니며, 확인 시간 초과 메시지도 상대에게 이미 도착했을 수 있어요.
- 전송 간격은 최소 0.7초, 수신은 다이버당 2초에 4개까지예요. 초과분은 버리고 다음 구간에서 다시 받아요. 텍스트로만 표시하며 수신 자료형·길이·순서를 검사해요.
- **공개 방** 하나를 공유해요. 개인 대화·비밀방이 아니며, 현재 방에 연결된 다른 클라이언트가 방송을 받을 수 있어요. 현재 Presence에 있는 알려진 다이버만 화면에 표시하는 것은 클라이언트 검사일 뿐 인증·발신자 위조 방지·보안 보장이 아니에요. 민감한 정보는 보내지 마세요.
- 앱은 채팅 기록을 저장하거나 조회하지 않으며 별도의 채팅 외부 API를 추가하지 않아요. 최신 말풍선과 제한용 숫자만 메모리에 유지해요. 서버·네트워크 운영 측의 로그 정책까지 보장한다는 뜻은 아니에요. 잠수 통계의 기존 브라우저 저장은 그대로예요.

## 이 장소로 초대하기

- 입수 후 오른쪽 위 **이 장소로 초대하기**를 누르면 현재 장면과 초대 링크를 확인할 수 있어요.
- 공유 이미지에는 수심과 X·Z 좌표, 다이브 타임, 함께한 인원, 초대 주소가 새겨져요.
- 링크에는 수심·X·Z 좌표와 시선 방향·상하 각도가 들어 있어요. 주소는 현재 배포된 사이트 주소를 자동으로 사용해요.
- 받는 사람이 링크를 열고 **초대 장소로 입수하기**를 누르면 해당 위치와 시선에서 시작해요. 움직이는 생물의 위치나 같은 장면까지 복원하지는 않아요.
- **초대 공유하기**는 지원되는 환경에서 기본 공유 창을 열어요. 이미지 파일 공유가 가능하면 이미지도 포함하고, 그렇지 않으면 링크를 공유해요. 대상 앱에 따라 이미지와 글 중 일부만 전송될 수 있으니 전송 내용을 확인해 주세요.
- **링크 복사**와 **이미지 저장**을 각각 사용할 수도 있어요. 사진에 적힌 주소 자체는 클릭할 수 없으니, 이미지와 초대 링크를 함께 보내 주세요.
- 자동 복사가 허용되지 않으면 입력란의 링크가 선택돼요. 직접 복사하면 돼요.
- 로컬 파일로 열면 초대 링크를 만들지 않아요. 배포된 사이트에서 사용해 주세요.

이 폴더를 GitHub에 올리고 Vercel에 연결하면 누구나 접속할 수 있는 사이트가 됩니다. 코딩 없이 웹 화면에서만 진행해요.

## 폴더 구성

- `index.html` : 사이트 본체 (3D 바닷속, 동시접속, 호흡 소리 모두 포함)
- `api/country.js` : 접속자의 국가를 IP로 알려주는 작은 서버 기능 (수트 국기용)
- `og.png` : 스레드, 카카오톡 등에 링크를 올렸을 때 뜨는 미리보기 이미지
- `README.md` : 이 안내서

Supabase 주소와 공개 키는 `index.html` 안에 이미 넣어 두었어요. 공개 키(publishable key)는 원래 웹페이지에 노출되도록 만들어진 키라 그대로 올려도 괜찮아요.

## 1단계. GitHub에 파일 올리기

1. github.com 에 가입하고 로그인해요.
2. 오른쪽 위 `+` 버튼에서 **New repository**를 눌러요.
3. Repository name에 `mulmit`을 입력하고 **Create repository**를 눌러요.
4. 다음 화면에서 **uploading an existing file** 링크를 눌러요.
5. 압축을 푼 폴더 안의 내용물(`index.html`, `og.png`, `README.md`, `api` 폴더)을 전부 선택해서 업로드 칸으로 끌어다 놓아요. 폴더 자체가 아니라 폴더 안의 내용물을 끌어다 놓아야 해요.
6. 아래쪽 **Commit changes**를 눌러요.

업로드 후 저장소 첫 화면에 `api` 폴더와 `index.html`이 바로 보이면 성공이에요.

## 2단계. Vercel로 배포하기

1. vercel.com 에서 **Continue with GitHub**로 가입해요.
2. **Add New → Project**를 누르고, 목록에서 `mulmit` 저장소의 **Import**를 눌러요.
3. Framework Preset은 **Other** 그대로 두고 **Deploy**를 눌러요.
4. 1분 정도 지나면 축하 화면과 함께 사이트 주소가 나와요. 예: `mulmit.vercel.app`

이후 GitHub에서 파일을 고치면 Vercel이 자동으로 다시 배포해요.

## 3단계. 주소 정하고 미리보기 주소 맞추기

1. Vercel 프로젝트에서 **Settings → Domains**로 가요.
2. `○○.vercel.app` 옆 **Edit**를 눌러 원하는 이름으로 바꿔요. 이미 쓰이는 이름이면 `mulmit-dive`처럼 바꿔 보세요.
3. GitHub 저장소에서 `index.html`을 열고 연필 아이콘(Edit)을 눌러요.
4. `https://mulmit.vercel.app` 이 세 군데 들어 있어요. 모두 실제 주소로 바꾼 뒤 **Commit changes**를 눌러요. (Ctrl+F로 `mulmit.vercel.app`을 찾으면 돼요.)

이 주소는 링크 미리보기 이미지가 뜨게 하는 용도라, 바꾸지 않아도 사이트 자체는 정상 작동해요.

## 4단계. 동시접속 확인하기

1. 휴대폰과 컴퓨터에서 각각 사이트에 들어가 둘 다 **입수하기**를 눌러요.
2. 오른쪽 아래가 "지금 2명이 함께 잠겨 있어요"로 바뀌고, 상대 다이버와 국기 태그가 보이면 성공이에요.

실제 배포 주소는 https://moolmit-zeta.vercel.app/ 이에요. 로컬 수정 내용은 재배포 전까지 이 사이트에 반영되지 않아요.

- 인원은 아바타나 위치 신호가 아니라 입수한 다이버의 Presence 키로 세어요. 입장 화면만 연 방문자는 등록하지 않으며, 본인은 중복 계산하지 않아요.
- 연결·재연결 중이거나 오류가 있으면 그 상태를 표시해요. 연결을 확인하지 못한 상태를 ‘혼자’ 또는 ‘조용한 바다’로 표시하지 않아요. 오류 시 **다시 연결** 버튼을 사용할 수 있어요.
- 구독과 최초 Presence 동기화 후 등록하고, 등록 결과가 `ok`일 때만 완료 처리해요. 등록 실패·시간 초과·연결 종료 시 상태를 비우고 최대 3회 자동 재시도해요. 버튼·온라인 복귀·페이지 복귀로 다시 시도할 수 있어요.
- 채널의 `presence.enabled: true`를 명시해 아직 입수하지 않은 구독자도 첫 Presence 동기화를 받을 수 있게 해요. 기존처럼 첫 동기화 뒤에만 등록하면서 이 옵션이 빠지면, 구독에 성공해도 등록이 시작되지 않을 수 있어요. 서버 설정은 변경하지 않아요.
- 첫 등록에 좌표·수심·시선·국가·호흡 기준을 담아 늦게 들어온 다이버도 상대를 바로 만들어요. 이후 받은 위치 방송을 오래된 등록 좌표로 되돌리지 않아요. 앱 복귀와 국가 변경 때도 안전하게 재등록해요.
- 계속 연결되지 않으면 개발자 콘솔의 `[mulmit realtime]` 작업·상태 코드와 두 기기의 표시를 함께 확인해 주세요. 진단 로그는 키·주소·원본 오류 객체를 출력하지 않아요. 연결 오류만으로 서버 설정 문제라고 단정하지 않아요.

## 운영할 때 알아둘 점

- **앱 입수 한도** : 다른 입수자 Presence 키가 이미 150개면 새 입수자는 "혼자 잠수" 모드로 들어가요(화면은 그대로 즐길 수 있어요). 본인과 미입수 방문자는 제외해요. `ROOM_CAP = 150`은 앱의 완화 장치이지 서버의 연결 한도나 동시 입수에 대한 원자적 예약은 아니에요. 입장 화면 방문자도 연결 자원은 사용해요. 요금제별 실제 한도는 제공업체에서 별도로 확인해 주세요.
- **메시지 한도** : 위치 신호는 움직일 때 초당 약 1.5회, 가만히 있을 때 5초에 한 번만 보내도록 줄여 두었어요. 그래도 사람이 많이 몰리면 무료 플랜의 월 메시지 한도에 빨리 닿을 수 있으니, 스레드 홍보 전에는 Pro 전환을 권해요.
- **일시 정지** : Supabase 무료 프로젝트는 오랫동안 사용이 없으면 일시 정지될 수 있어요. 대시보드에서 다시 켤 수 있어요.
- **Vercel 무료 플랜** : 개인적, 비상업적 용도용이에요. 회사 마케팅으로 운영한다면 Pro 플랜이 필요한지 Vercel 요금 페이지에서 확인해 주세요.
- **미리보기 이미지 갱신** : 링크를 한 번 공유한 뒤 이미지를 바꾸면 예전 이미지가 남아 있을 수 있어요. Facebook 공유 디버거(developers.facebook.com/tools/debug)에 주소를 넣고 다시 가져오기를 누르면 스레드와 인스타에도 반영돼요.

### 서식 구역 지도

좌표는 X·Z, 수심은 관찰 권장 범위예요. 지형 위에서는 바닥 관통을 막기 위해 실제 수심이 제한될 수 있어요.

| 구역 | 중심 X·Z | 관찰 수심 | 이어지는 물길 |
|---|---|---|---|
| 갈라진 현무암 가장자리 | 0, 0 | 8–18m | 은빛 물길 / 거북 돌턱 / 해협 |

### 개발 검증

상위 작업 폴더의 `test_realtime.cjs`는 실제 실시간 코드 블록을 가짜 채널·가상 시간으로 실행해 등록 성공/반환 오류/거절/시간 초과, 제한된 재시도, 재접속, 입수 시점, 인원·초기 아바타, 늦은 입장 좌표, 퇴장, 오래된 비동기 결과, 정원 판정과 국가 재등록을 검사해요. `node test_realtime.cjs`로 실행하며 서버 설정이나 배포본을 바꾸지 않아요.

`test_chat.cjs`는 실제 채팅 코드를 가상 시간으로 실행해 텍스트 안전성·길이·수신 필터·중복·갱신·페이드·정리·전송 실패·한글 조합·키보드 보호를 검사해요. `_chat-test-desktop.html`, `_chat-test-mobile.html`은 가짜 상대와 연결을 주입한 **시각 검사용 임시 시뮬레이션**이며 운영 코드나 배포 대상이 아니에요.

상위 작업 폴더의 `test_galapagos.cjs`는 실제 r128 형상과 이동 함수를 실행해 구역 간격, 연결성, 개체 수, 바닥 부착, 고정 서식지, 범고래의 비추격 경로와 정적 구문을 검사해요. `test_mobile.cjs`, `test_invite.cjs`도 기존 조작·초대 호환성을 검사해요. `_galapagos-*.html`은 장면별 자동 입수 검사용 임시 파일이며 배포 대상이 아니에요. 읽기 전용 `window.__mulmitGalapagos.snapshot()`으로 현재 구역·개체 수·그리기 호출 수를 확인할 수 있어요.

- **인사하기** : 오른쪽 아래 버튼 또는 G 키. 주변 다이버가 손을 흔들어 응답해요.
- **만난 생물 도감** : 고래상어·만타가오리·바다거북·정어리 떼·리프상어·큰돌고래·바라쿠다 떼·흰동가리를 가까이서 1.5초 이상 보면 기록돼요.
- **심해 연출** : 수심 22m 아래에서 생체발광 플랑크톤이 반짝이고, 20m보다 깊으면 가끔 고래 노래가 들려요.

- **리프상어 2마리** : 기존 고래상어와 별개예요. 약 2.4~2.5m의 유선형 몸, 삼각 등지느러미, 위쪽이 긴 수직 꼬리, 다섯 아가미와 좌우 꼬리 운동을 표현했어요.
